# v1.5.12 R-145 Pre-UX PDF Foundation

v1.5.12 closes the PDF rendering, selectable-text, selection-coordinate, and extraction/cache foundation before the separately scoped v1.6 Reader visual redesign. It preserves the v1.5.11 Library to Paper Detail to Reader workflow and does not add Research Block capture or persistence.

Canonical mutable validation and publication state is recorded in [Current Release Status](../CURRENT_RELEASE_STATUS.md).

## Included

- PDF.js canvas backing buffers use a bounded `1..2` device-pixel output scale while CSS viewport dimensions and semantic Reader zoom remain unchanged.
- PDF.js text layers share the canvas page viewport, rotation, zoom, cancellation, retry, fallback, document-change, and unmount lifecycle.
- The internal selection contract uses canonical 1-based BluePrint page numbers and top-left rectangles normalized to the rotated logical page viewport.
- Optional `pdf-inspector==0.2.6` is isolated behind BluePrint-owned structured document/page/position models. Its 0-based page-Markdown fields and 1-based OCR/position fields are normalized at the adapter boundary.
- Structured extraction records text/scanned/image-based/mixed classification, confidence, page count, per-page text/Markdown/positioned items, OCR-needed pages/reasons, warnings/errors, and provider identity/version.
- Cache metadata adds explicit extraction/cache state, structured output, and reusable OCR-needed results while retaining SHA-256 stale detection and prior-valid-cache preservation.
- MarkItDown and pypdf remain compatibility fallbacks when the optional dependency is absent, fails, or produces no locally usable text.

## Excluded

No OCR engine, semantic/full-text search UI, background extraction, automatic scheduling, selection/highlight persistence, Note Block or Research Block creation, drag/drop, Reader visual redesign, installer, database migration, or `paper_id` change is included.

- GitHub Actions, PR, merge, tag, GitHub Release, post-merge validation, and clean-PC restore are **NOT VERIFIED** unless separately observed.
