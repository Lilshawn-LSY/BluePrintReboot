# v1.5.13 Integrity and Reliability Hardening

v1.5.13 is a bounded pre-design reliability pass. It changes no database, hosted-service, multi-user, or visual architecture.

## Included

- Backup snapshots are workspace-locked, manifest exact archived bytes, verify before atomic publication, include Tag Candidate review state, and verify ZIP members with bounded streaming reads.
- `tag_candidate_reviews.json` is part of the shared persistent-state registry used by backup, Health, and Settings.
- Full Text and Tag Candidate multi-write commands use explicit order, verification, rollback, idempotent retry, and the common workspace lock.
- Duplicate/missing PDF repair, rename/import, metadata/tag, Project, Note Block, note-import, lifecycle, and legacy Tag Manager writes participate in the same lock strategy.
- Health detects malformed JSON items and paper-index identity/schema violations without repair. Related read models reuse a one-second, mutation-invalidated Health snapshot.
- Reader, PDF serving, and Full Text share a `papers/`-bounded PDF resolver with filename-only legacy fallback. Reader snapshots use one coherent index read.
- `load_index()` is read-only; explicit `migrate_index_storage()` owns persisted migration and SHA-256 backfill.
- Exact PDF identity is recomputed from current bytes, including same-size/same-mtime replacements.
- Safe `paper_id` validation protects filename-backed stores. Atomic replace now best-effort fsyncs the parent directory.
- Projects, Paper/Project selectors, Reader tags, and Project links no longer stop at 100 items. Reader mutations are exclusively coordinated.
- The same-origin API bridge bounds command bodies at 8 MiB and applies a two-minute upstream timeout while preserving streamed PDF responses.

## Compatibility and safety

Valid existing paper IDs and response contracts are unchanged. No automatic repair, data migration during reads, PDF move/delete, candidate application, or cache overwrite is introduced. Existing malformed state remains on disk for explicit recovery and is surfaced as corrupt rather than empty.
