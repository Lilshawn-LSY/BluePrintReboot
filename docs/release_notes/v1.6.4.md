# v1.6.4 — Visual hierarchy & density pass

v1.6.4 is a focused presentation and interaction refinement for the desktop
research workspace. It adds no backend capability, storage migration, or
automatic save behavior.

## Reader

- Reader top chrome is compact: breadcrumbs retain Paper identity, Tags and
  Full Text remain direct controls, and ordinary active lifecycle state is
  quiet. Exceptional lifecycle state remains visible where relevant.
- Paper context is informational only. Paper Note and metadata SaveStatus
  appear only beside their relevant editor.
- Paper Note formatting uses compact icon controls with accessible labels and
  titles while preserving the existing Markdown, selection, keyboard, preview,
  draft, and explicit Save behavior.
- Tags and Full Text drawers name the active utility and retain their existing
  overlay, focus restoration, Escape, and PDF-position behavior without a
  duplicate utility tab switcher.

## Project Detail, Dashboard, and shell

- Project Detail uses a compact metadata summary, promotes linked Papers and
  Note Blocks, and renders them as denser navigation rows. Edit Project stays
  primary; Reload and Archive are visible in a secondary disclosure, and link
  removal remains explicitly confirmed.
- Dashboard has a readable workspace width and a compact Continue reading
  empty state. It keeps the existing safe draft-count presentation rather than
  inferring draft ownership from browser storage.
- The sidebar no longer shows the product version in ordinary chrome. Settings
  uses a secondary navigation group, and the collapse control is icon-first
  with an accessible name and title.
- Shared page-archetype width modifiers and a slightly darker muted-text token
  improve coherence and small-text readability without changing the neutral
  green/ivory direction.

## Safety and validation scope

No backend persistence contract changed. Explicit server Save remains
authoritative; browser-local drafts, revision/conflict handling, archive
behavior, managed-PDF safety, and Reader PDF fit/zoom behavior remain intact.

Automated validation covers structural and interaction safeguards. User browser
verification at 1920px, 1440px, 1366px, and 1280px remains outstanding and is
not claimed here; see the generated [Current Release Status](../CURRENT_RELEASE_STATUS.md).
